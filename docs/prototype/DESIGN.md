# 原型设计约定

使用 React 与本地模拟数据，所有文件均位于本原型目录，不连接后端。

## 公共组件（先于业务页面设计）

- 顶部导航：品牌、订单、发票、提供商、发票抬头、全局搜索入口。
- Button / Badge：统一按下反馈、焦点、禁用原因及状态色。
- Modal：原生 dialog 焦点约束、Escape 关闭、表单与详情共用。
- Field：统一标签、输入尺寸、必填和错误反馈。
- Table：固定表头、块内滚动、隐藏滚动条、全选和空态。
- CopyButton：编号自身可复制，结果通过状态提示反馈。
- 卡片：提供商与抬头共享布局、复选框和底部操作。

## 视觉与行为

遵循 AppleDesign：系统字体、浅灰画布、白色内容层、半透明顶部导航、
蓝色主要操作、克制的阴影、清晰的文字层级及即时按下反馈。
不使用侧边导航。表单和详情使用居中浮层，避免复杂手势。
提供减少动画、减少透明度及增强对比度适配。

## 已确认业务约定

- 未开票订单类型显示“—”，开票时选择抬头。
- 回收站支持单条与批量恢复。
- 正常订单仅移入回收站；回收站仅永久删除。
- 已开票订单禁止修改和任何删除；回收站订单禁止修改、开票。
- 合并开票支持不同提供商，使用统一抬头，金额由整数分相加。
- 发票作废后解除订单关联，订单可重新开票；作废发票保留。
- 提供商、抬头删除不以关联记录阻止；缺失引用显示“已删除”。
- 搜索包含回收站与作废记录、关联提供商和抬头；不截断结果。
- 搜索跳转清除目标页筛选并滚动定位，目标高亮 1 秒。
- 日期筛选使用更新时间的起止日期，包含所选日期全天。

## 原型边界

“开票”为记录发票并关联订单，不生成发票文件，不支付或发放 Token。
数据仅保存在本地浏览器；初始内容均为示例。实际接口接入在后续前端实施中进行。
