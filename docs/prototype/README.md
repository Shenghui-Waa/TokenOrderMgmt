# Token 订单管理 · React 交互原型

直接用桌面浏览器打开本目录的 **index.html**。
构建产物已经包含在 `dist/` 中，无需安装依赖、启动服务或连接后端。

## 内容

- 顶部导航：订单、发票、提供商、发票抬头。
- 全局搜索：大小写无关的模糊匹配、全部结果、跨页面定位并高亮 1 秒。
- 订单：全部加载、块内滚动、筛选、复制编号、详情、添加和修改。
- 开票：单笔和多笔合并、抬头选择、金额合计、发票详情及作废解绑。
- 回收站：单条和批量恢复、永久删除，已开票订单禁止删除。
- 发票：更新时间、类型、状态筛选；详情包含关联订单。
- 提供商与抬头：卡片展示、添加、修改、单条和批量删除。
- 操作限制、删除确认、空结果提示、键盘焦点和即时反馈。

搜索入口也可使用 `Ctrl+K`（macOS 为 `⌘K`）。
列表不分页，鼠标滚轮在列表区域内滚动；滚动条隐藏。
日期范围包含起止日期全天。未开票订单的发票类型显示“—”。
提供商网址作为文字展示，通过独立的“访问网站”按钮打开新标签页。

## 数据与边界

首次打开载入示例数据：30 条正常订单、3 条回收站订单、6 家提供商、
4 个发票抬头、2 张有效发票和 1 张作废发票。
更改保存到当前浏览器的 localStorage。底部“重置示例数据”可恢复初始内容。
若浏览器限制本地文件存储，页面会提示更改仅在本次打开期间保留。

本原型不会读取或修改业务数据库。开票仅模拟登记发票及订单关联，
不会生成电子发票文件、支付款项或发放 Token。
发票关联订单目前由模拟数据查询；正式接入时使用 `GET /token-order/i/{id}`。
发票作废后解除关联，已作废发票的关联列表因此为空，与接口行为一致。

后端 README、接口文档及后端源码均未修改。

## 维护

在本目录使用 PowerShell 7：

```powershell
npm ci
npm run build
npm test
```

修改源码后先构建再测试，测试会加载最新 `dist/app.js`。
没有配置自动启动服务。React、React DOM、esbuild 和测试用 jsdom 均在依赖文件中声明。

## 文件

- `DESIGN.md`：公共组件、视觉与交互约定。
- `src/components.jsx`：按钮、状态、弹窗、表单字段、表格和空态。
- `src/main.jsx`：四个功能页与交互。
- `src/styles.css`：集中维护的独立样式。
- `src/model.js`：模拟数据、搜索与业务操作。
- `src/model.test.js`、`src/ui.test.js`：业务与 DOM 交互测试。
- `VERIFICATION.md`：验证范围和限制。
